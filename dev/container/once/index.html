    Once#

    Primitives for containers that can be written only once. Inspired by :rust OnceCell and :rust LazyCell.

    The Once and Lazy classes, are exposed in the package namespace.

    Implementation#

    Once takes reference from :rust OnceCell and the current status is as follows:

    Lazy #

    A container that can be lazily initialized only once. The stored function will be actually called only on the first retrieval, and the result will be cached for consequent calls. See :rust LazyCell for more information.

    This class is exposed in the package namespace.

    Example 
    from apfel.container.once import Lazy

@Lazy
def func():
    print("called")
    return object()

obj = func.value()
# print "called"
# here, the function `func` will be called and the result will be cached.

func.value() is obj # the function `func` will not be called again.

    __call__() #

    An alias for Lazy.value. Notice that this operator overloading might be slower than calling value directly.

    Example 
    @Lazy
def func():
    return object()

obj = func()
assert func() is obj
